# Simulator walk-in Lab TJKT

Situs statis satu file (index.html). Three.js dimuat dari CDN cdnjs, jadi tidak ada proses build.

## Deploy ke Vercel
1. Ekstrak zip ini.
2. Cara termudah: buka vercel.com/new, pilih "Deploy" lalu seret folder ini. Framework preset: Other, tanpa build command, output directory dikosongkan.
3. Atau lewat CLI: `npm i -g vercel`, lalu jalankan `vercel --prod` di dalam folder ini.

## Kontrol
- Komputer: W A S D atau panah untuk jalan, geser mouse untuk melihat, Shift untuk lari.
- HP: putar ke landscape, geser sisi kiri untuk jalan, sisi kanan untuk melihat, tombol Lari di kanan bawah.
